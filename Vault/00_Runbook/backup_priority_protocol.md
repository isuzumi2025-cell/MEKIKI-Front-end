# バックアップ優先プロトコル

> **絶対ルール**: 新規実装・修正前に必ずバックアップを確認

## チェックリスト（全作業前に実行）

### 1. 機能特定

- [ ] 修正対象機能を明確化
- [ ] 関連ファイル名を特定

### 2. バックアップ検索（必須）

```powershell
# 例: サムネイル連動
grep -r "_on_thumbnail_click" Desktop/26/OCR_backup_* --include="*.py"
```

### 3. 評価・選定

- [ ] 複数バックアップを比較
- [ ] 最短・最シンプルを選定
- [ ] canonical/に登録

### 4. 適用

- [ ] 差分確認
- [ ] A/Bテスト
- [ ] 承認後に本番反映

## 禁止事項

❌ バックアップ確認なしの新規実装
❌ 動作版があるのに「修正」を試みる
❌ 複雑化する改変

## 許可事項

✅ 動作版の直接転送
✅ 必要最小限の統合調整
✅ Obsidianへの正本登録
