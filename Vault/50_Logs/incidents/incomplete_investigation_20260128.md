# 🚨 アンチパターン記録: 不完全調査

**記録日**: 2026-01-28
**問題**: ディープリサーチが限定的で、全バックアップを調査しなかった

---

## 発生した問題

1. **18個のバックアップがあると認識しながら2つしか調査しなかった**
2. **LegacyOCRの存在をユーザーに指摘されるまで見落とした**
3. **「完了」と報告したが実際は10%未満しか調査していなかった**

## 根本原因

- 「代表的なファイルを見れば十分」という誤った前提
- 調査範囲の明確な定義なしに着手
- 進捗率の定量的追跡を怠った

## 改善プロセス

### 必須チェックリスト

1. [ ] **全対象のリストアップ**を最初に行う
2. [ ] **各対象に評価ステータス**を付与する
3. [ ] **定量的進捗率**（N/M完了）を報告する
4. [ ] **未調査項目を明示**してから完了報告する

### 調査開始時の必須コマンド

```powershell
# 全バックアップを列挙
Get-ChildItem -Directory | Where-Object { $_.Name -match "OCR|backup|Legacy" }
# ファイル数を確認
Get-ChildItem -Recurse -File *.py | Measure-Object
```
